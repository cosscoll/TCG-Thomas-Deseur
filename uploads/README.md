# Dépôt de l'archive des 161 illustrations

Déposez ici **un seul fichier** nommé exactement :

`TCG_Deseur_161_Visuels_WEBP_GitHub.zip`

Le workflow [Importer les 161 illustrations](../.github/workflows/import-card-art.yml) vérifie l'archive et en extrait automatiquement les 161 images dans `collection-161/assets/cards/`.

**Ne pas ajouter les 161 WebP un par un.** Ne pas renommer l'archive.

Le fichier ZIP est fourni dans la conversation ChatGPT qui a préparé le catalogue. L'ancien set de 49 cartes et les collections réelles Floot restent inchangés tant que la migration sécurisée côté Floot n'est pas publiée et testée.
