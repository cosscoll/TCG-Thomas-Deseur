03 ÉTAPES

Comment participer au test

01

Crée ton compte

Sur le site du jeu, ouvre l'espace de connexion, choisis l'inscription, renseigne ton adresse e-mail, un pseudonyme et un mot de passe personnel. Si tu as déjà un compte, connecte-toi.

02

Ouvre un booster

Depuis ton espace joueur, essaie d'ouvrir un booster de cinq cartes et de découvrir les cartes reçues. Le rythme normal prévu est d'un booster gratuit toutes les 24 heures par compte.

03

Vérifie ton classeur

Retrouve les cartes reçues dans ta collection. Actualise la page puis reconnecte-toi : elles devraient toujours être présentes. Note ce qui fonctionne ou non.

La collection approuvée de 67 personnages et leurs illustrations est visible dans le catalogue de référence. Son intégration au jeu connecté n'est pas encore terminée : les cartes affichées dans le jeu peuvent différer pour le moment.
